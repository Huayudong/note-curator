# 文风学习

## 显式学习（默认）

修改完一篇笔记后说「学习这篇的写法 / 学习这次修改」：

1. `learn_edit.py diff` 对比基线与当前版本，差异分类为事实/内容/结构/表达/排版；
2. 只从表达与排版类提炼**偏好候选**；向用户展示；
3. 确认（`confirm`）才生效，拒绝（`reject`）、撤销（`undo`）随时可用。

持续并入统计画像用 `style_learn.py`（同一篇多次改稿按内容哈希识别为修订刷新）。

## 学习模式（B06）

`config style.learning_mode`：

- `off`：不学习；
- `explicit`（默认）：显式触发才学；
- `assisted`：汇总候选待批量确认；
- `auto`：跨 ≥2 篇独立笔记的同类表达候选自动生效；事实与冲突仍进待确认。

## 偏好管理

`preferences.py list / disable / enable / forget / export / import / conflicts`：

- 停用可逆（enable 恢复）；忘记会删除事件证据并废弃派生偏好；
- 导出只含偏好与元数据，不含原文证据；
- active 偏好自动参与写入前检查（限同语言作用域）。

## 边界

- 只学习用户改稿；AI 生成的原稿、引语、代码不会成为个人样本；
- 事实修正只进事实记录，不转文风偏好；
- 单纯点击保存不是学习信号。
