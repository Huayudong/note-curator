# 隐私

## 默认留在本地

- 笔记内容：只在你的 vault，不复制出库；
- 个人学习资料（改稿证据、偏好、画像、反馈）：`~/.note-curator/`（或
  `NOTE_CURATOR_HOME`），默认不上传、不同步、不进公共语料；
- 公共语言包在技能目录 `language-packs/`，与个人资料物理分离。

## 会发送给模型的内容

使用远端模型时，实际进入上下文的是：来源片段（截断至 6000 字）、语言包
规则要点、画像摘要与 active 偏好——按任务最小化。API key 通过环境变量
或插件本地数据传入，仅出现在 Authorization 头，不写入笔记、日志或随
vault 同步的文件。**本地保存 ≠ 推理离线**，两者在文档中分开表述。

## 保留期限（默认，可调整）

| 资料 | 默认 |
|---|---|
| 写入恢复备份 | 30 天 |
| 生成基线 | 90 天 |
| 写入计划 | 90 天 |
| 显式偏好 | 删除前持续有效 |
| 反馈 | 仅本地，删除前有效 |

## 忘记与删除

- `preferences.py forget`：删除学习事件与候选证据，派生偏好标记 forgotten；
- `preferences.py export`：只含偏好与元数据，不含原文证据；
- `doctor.py --clean`：按保留期限清理计划/基线/备份；
- 诊断输出脱敏：用户目录显示为 `~`，不含笔记内容。
